# Job Portal System

## Description

A simple Job Portal System developed using Python. The system allows companies to post jobs and users to view, search, and apply for available jobs.

## Features

- Post a job
- View available jobs
- Search jobs by title or skill
- Apply for a job
- View job applications
- Menu-driven interface

## Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements

## How to Run

1. Open the project folder in VS Code.
2. Open `job_portal.py`.
3. Run the Python program.
4. Select an option from the menu.

## Menu Options

1. Post Job
2. View Jobs
3. Search Jobs
4. Apply for Job
5. View Applications
6. Exit

## Conclusion

This project demonstrates the implementation of a basic job portal system using Python data structures, functions, and user input.
